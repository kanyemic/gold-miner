# 黄金矿工 · Gold Miner

经典「摆锤拉钩」玩法的现代 Web 重制版，纯前端单页架构，无外部资源依赖，双击即玩。

---

## 游戏特点

- **真实物理回拉**：纯数学几何计算绳索摆动与射线抓取。不同矿物重量不同，回拉速度明显分层（如钻石 305px/s vs 巨石 92px/s）。
- **完整道具闭环**：
  - **🧨 炸药（快捷键 B）**：钩到沉重无用的巨石时果断引爆，立即收回空爪。
  - **💪 力量药水（快捷键 S）**：当前关卡全场回拉速度 +75%。
  - **🍀 幸运草（快捷键 L）**：当前关卡所有矿物结算价值 +35%。
- **神秘口袋**：概率开出碎石（20金）、金币（110~220金）、稀有宝石（380金）或整袋大金（700金），兼顾风险与惊喜。
- **关卡与商店**：内置 10 个梯度配置关卡。关卡结束后可使用钱包余额在商店补给道具。
- **Web Audio 原生合成**：无需加载任何外部 mp3 音频，完全由代码合成出钩、命中、拉金、爆炸、金币入账等音效。
- **全平台支持**：支持键盘（空格/方向键下放钩、B/S/L道具快捷键、Esc/P暂停、M静音）及移动端触控。

## 文件目录

```text
gold-miner/
├── index.html        # 游戏入口（语义化 DOM 与 HUD 布局）
├── styles.css        # 矿山质感样式与响应式缩放
├── game.js           # 物理引擎、渲染管线、状态机与关卡表
├── README.md         # 游戏说明
└── tests/
    ├── harness.mjs   # 无头 DOM/Canvas 运行桩
    ├── smoke.mjs     # 25 项全量核心逻辑冒烟断言
    └── balance.mjs   # 3 种玩家行为画像的 10 关蒙特卡洛平衡性仿真
```

## 运行方式

### 方式一：浏览器直接双击打开
在文件管理器中直接双击 `index.html` 即可运行。

### 方式二：本地静态服务
```bash
cd gold-miner
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```
